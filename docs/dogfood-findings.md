## Open investigations

- ~~**Qwen submit-tool quirk:**~~ **Resolved.** Added no-op `submit` tool (`crates/tools/src/submit.rs`) — models that call it now get success instead of "Tool not found", so sessions no longer end in "failed" status.
- ~~**Layer 3 edge coverage gap (ndstrms):**~~ **Resolved.** Root cause: `layer25_metadata` was keyed by CHUNK node IDs (from `add_parser_selection_metadata`), but Layer 3's `_parse_file` expected FILE node IDs. CHUNK nodes have `file_path` attribute, Layer 3 looked for `path` → got None → skipped all files. Fix: added `parent_file_id` to candidates, remapped in `full_graph.py` with file-level deduplication. Secondary fix: lowered `min_confidence_for_parsing` from 0.7 to 0.3. Commit bc01de7.
- ~~**Mistral embedding token limit (ndstrms):**~~ **Resolved.** `char_limit` changed from `MAX_TOKENS * 4` to `MAX_TOKENS * 3` (more conservative for minified code); `MAX_TEXT_LENGTH` updated to 24000. Commit 59b24a6.
- ~~**Cache deduplication (ndstrms):**~~ **Resolved.** `iter_cached_repo_entries` now deduplicates by `repo_path`, keeping the entry with the latest `last_accessed`. Commit 59b24a6.
- ~~**`.git/` chunking (ndstrms):**~~ **Resolved.** `dirs[:]=` filter in `FileTreeWalker.walk()` prunes `.git` (and `__pycache__`, `node_modules`, `vendor`) before descending; `_should_skip_file` also checks path parts for hidden dirs. Commit 59b24a6.
- **Pre-existing test_backend.py failures:** 6 tests in `tests/test_embedding/test_backend.py` fail due to hardcoded error message regex and empty-API-key behavior — pre-existing, not caused by recent changes. Should be fixed to prevent masking regressions.
- ~~**Embedding 400 token-limit retry loop (ndstrms):**~~ **Resolved.** Previous retry loop resent the same oversized payload on every attempt — 3 identical 400s, then whole repo failed. Fix: catch-and-trim in `_embed_one_batch` — detect `"Input id N has X tokens, exceeding max 8192 tokens"`, parse index, halve text, `continue` without counting as a retry. Cap trim retries at 3. Commit c3bc394.
- ~~**False-positive hidden-dir skip in `_should_skip_file` (ndstrms):**~~ **Resolved.** The `pipeline-fixes-3` parts-check (`any(part.startswith(".") for part in Path(file_path).parts)`) matched `.cache` in the absolute cache path `/root/project/.cache/repos/...`, causing every file in every cached repo to be skipped → zero FILE nodes → zero CHUNKs → all downstream layers no-ops. Fixed by removing the redundant parts-check (the `dirs[:]=` filter in `walk()` already prevents descent into hidden dirs). Commit 481bc55.
- **Shared EmbeddingCache across batch repos (backlog):** Each `run_full_graph_pipeline` call creates a fresh `EmbeddingCache`; a single shared instance passed to the batch loop would avoid re-embedding identical chunks across repos. Added to ndstrms `BACKLOG.md` item 10 (ff44fb7).

- **Parallel chunking + adaptive token-budget scheduler (backlog):** `_chunk_all_files` is single-threaded on an 8-core machine (~8x speedup with `ProcessPoolExecutor`, item 11). Mistral embedding calls replaced with sliding-window `TokenRateLimiter` driven by `tokens_per_minute = 5_000_000` config (item 12, 2bb0b2f).
